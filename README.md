# Star Trek Favorite Movies App

A mobile-friendly app built with **Ionic (Angular)** using **NGXS** for state management and **Jest** for testing. It allows users to view and favorite Star Trek movies, as well as change the language of movie titles.

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone git@github.com:mersimoski/star-trek-movies.git
cd star-trek-movies
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
ionic serve
```

---

## 🧪 Running Tests

To run unit tests:

```bash
npm run test
```

Tests are written using [Jest](https://jestjs.io/) and cover key logic in the app (title localization, language selection, etc.).

---

## 📦 Tech Stack

- **Ionic Framework (Angular)**
- **NGXS** for state management
- **Jest** for testing
- **TypeScript**

---

## 📂 Folder Structure Highlights

- `src/app/tab1` – All Movies screen (Home)

- `src/app/tab3` – Settings screen
